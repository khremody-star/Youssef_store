متجر يوسف — ملفات الموقع

المحتويات:
- index.html: صفحة المتجر.
- ضع ملف تطبيقك بجانب index.html وسمّه app.apk حتى يعمل زر التحميل.

النشر المجاني باستخدام GitHub Pages:
1) أنشئ حسابًا على GitHub بمساعدة ولي أمرك.
2) أنشئ مستودعًا جديدًا (New repository).
3) ارفع index.html وملف app.apk إلى المستودع.
4) من Settings ثم Pages اختر النشر من الفرع main والمجلد /(root).
5) انتظر ظهور رابط الموقع في صفحة Pages.

مهم:
- ملف APK غير مرفق لأنني لا أملك ملف التطبيق في هذه المحادثة. أضف ملف APK الذي بنيته أنت.
- لا ترفع أي ملف إلا إذا كنت متأكدًا أنه النسخة الصحيحة والآمنة من تطبيقك.
- Google Play يتطلب حساب مطوّر مدفوعًا؛ هذا الموقع بديل مجاني للتوزيع عبر رابط، وليس متجر Google Play.
